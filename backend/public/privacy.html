PRIVACY POLICY

This site does not keep a child's questions.

Last updated 23 September 2026.

askwatima.com is the project page. It does not create an account, and a child's question never arrives here. The software, when you run it, stores data in the Firebase project you deploy.

This website

  • No account. There is no public sign-in. Visiting this page does not identify you.
  • No analytics. No tag manager, advertising pixel, or session recording. The only outside service the page loads is Google Fonts, for the typefaces.
  • Email. If you write to hello@askwatima.com, that message is the only thing this site's author receives from you.

When you run the software

The firmware sends audio to the function you deployed. The function turns it into text, asks a model for an answer, and speaks that answer back. The reference function discards the audio. It does not write a recording.

What can be kept is the text of the question and the answer, with the device id and a time. You choose that on the device, in the dashboard you run:

  • Off — nothing is written.
  • Session (the default) — kept for one day, so a follow-up can use the last hour of the conversation.
  • Persistent — kept for 30 days, so you can read it back.

The dashboard in the repository signs a parent in with Google against your Firebase project. That name and email stay in that project. This website does not receive them.

If the function calls Gemini, Google processes that turn. Self-hosting means this project does not keep a second copy of the log. You do, in the database you run.
